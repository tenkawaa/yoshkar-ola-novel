# Йошкар-Ола — интерактивный путеводитель

Небольшой веб-проект в формате визуальной новеллы для виртуальной прогулки по Йошкар-Оле. Игрок проходит по сценарию, читает диалоги и выбирает варианты маршрута.

## Что внутри

- **Сценарий с выбором ответа:** Ветвление диалогов, переходы между локациями и персонажами.
- **Печатающийся текст:** Эффект постепенного вывода реплик с возможностью пропустить анимацию кликом или клавишей `Enter`.
- **Управление:** Игра полностью проходима как мышкой/тапом, так и с клавиатуры (`Enter`).

## Стек

- **Vue 3** (Composition API, `<script setup>`)
- **Vite** (сборка и dev-сервер)
- **Tailwind CSS** (стили)

## Запуск проекта

Для работы потребуется Node.js (версии 18 или новее).

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/your-username/yoshkar-ola-novel.git
   cd yoshkar-ola-novel
   ```

2. Установить зависимости:
   ```bash
   npm install
   ```

3. Запустить в режиме разработки:
   ```bash
   npm run dev
   ```

4. Собрать production-версию:
   ```bash
   npm run build
   ```

## Как редактировать сценарий

Весь текст, списки выборов и привязка спрайтов/фонов лежат в `src/config/scenario.js`. 

Каждая сцена представляет собой объект:
```javascript
my_scene: {
  speaker: 'Имя персонажа',        // без speaker — текст рассказчика
  bgKey: 'название_фона_из_assets', // не указан — остаётся фон прошлой сцены
  characterKey: 'cat',              // не указан — остаётся прежний, null — убрать
  emotion: 'happy',                 // neutral, happy, point, surprised, thinking, sly, sad
  stop: 'gallery',                  // точка маршрута из ROUTE (индикатор сверху)
  text: 'Текст реплики...',         // или функция (vars) => строка
  nextId: 'следующая_сцена'         // или функция (vars) => id, или choices: [...]
}
```

Вариант ответа может менять переменные прохождения:
```javascript
{ text: 'Красный город', nextId: 'quiz_right', add: { score: 1 }, set: { wish: true } }
```

Финальная сцена помечается `isEnd: true` и `ending: { title, text }` — это текст экрана концовки.

В dev-режиме сценарий проверяется при запуске (`src/engine/validate.js`): ссылки на несуществующие сцены, фоны и эмоции выводятся в консоль браузера.

Во время игры: клик / `Enter` / пробел — дальше, `1`–`3` — выбор ответа.

## Гид

Спрайты Йошкина кота сгенерированы в Nano Banana (белый фон вырезан), лежат в `public/assets/characters/cat/<эмоция>.webp`. Эмоции: `neutral`, `happy`, `point`, `surprised`, `thinking`, `sly`, `sad`.
